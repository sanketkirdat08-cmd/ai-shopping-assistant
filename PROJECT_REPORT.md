## 2. ABSTRACT
This industrial training report presents the comprehensive work completed during the In-Plant Industrial Training at **Indradeep Information Technology Pvt. Ltd., Satara**. The training was focused on modern web engineering using **Visual Studio Code (VS Code)**, **Node.js/npm**, **React.js**, **Vite**, **Modern JavaScript (ES6+)**, and **Google Gemini Generative AI API**.

As part of practical learning, a full-featured capstone application—**"AI Shopping Assistant (Nexa Cart)"**—was designed and developed. It features:
- Dark Neon futuristic user interface with CSS Flexbox & Grid.
- Real-time conversational AI shopping chatbot (*Ask Nexa*) powered by Google Gemini API (`gemini-flash-latest`) with intelligent Marathi/English support.
- Live catalog filtering across 100+ items with interactive price slider (₹1 to ₹2,00,000).
- Product quick-view, side-by-side comparison matrix, dynamic cart with Add/Remove toggle, Buy Now checkout with Cash on Delivery, order tracking history, and an administrative analytics dashboard.
- Client-side persistence using HTML5 LocalStorage API for offline resilience.

## 5. CAPSTONE PROJECT: "AI SHOPPING ASSISTANT (NEXA CART)"
### Technologies Used:
- **Code Editor:** Visual Studio Code (VS Code)
- **Frontend Framework:** React.js 18+
- **Build Tool:** Vite 6+
- **AI Brain:** Google Gemini 2.5 Flash Generative AI API
- **Language:** JavaScript (ES6+) / HTML5 / CSS3
- **Icons:** Lucide React
- **Data Persistence:** LocalStorage CRUD Layer

### Modules Implemented:
1. **Interactive AI Concierge (Ask Nexa):** Intelligent Marathi & English shopping advice, budget matching, and product recommendations.
2. **Dynamic Product Catalog:** Real-time search, price range filter (₹1 to ₹2,00,000), and 6+ category tabs.
3. **Cart & Wishlist Engine:** Add to Cart, Remove from Cart toggle, Buy Now flow, persistent storage.
4. **Compare Matrix:** Side-by-side specifications comparison across 3 items.
5. **Checkout & Order History:** Address validation, Cash on Delivery, order history timeline.
6. **Admin Dashboard:** Inventory management, product addition form, sales revenue statistics.
